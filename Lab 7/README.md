# ARTI402 – Lab 07: Deep Learning with Keras

## Description
This lab explores building and training neural networks using TensorFlow and Keras, focusing on overfitting and regularization techniques.

## Tasks Completed
- Built a neural network using Keras.
- Trained and evaluated the model using Adam Optimizer.
- Applied L2 Regularization and Dropout.
- Implemented Early Stopping.
- Compared model performance using training and validation accuracy.
- Visualized decision boundaries and training curves.

## Tools and Libraries
- Python
- TensorFlow / Keras
- NumPy
- Matplotlib

## Conclusion
This lab demonstrates how regularization techniques such as L2, Dropout, and Early Stopping can help reduce overfitting and improve model generalization.
