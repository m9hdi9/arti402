# ARTI402 – Lab 08: Deep Learning with PyTorch

## Description
This lab explores building, training, and evaluating neural networks using PyTorch, focusing on automatic differentiation, backpropagation, and training loops.

## Tasks Completed
- Implemented automatic differentiation using Autograd.
- Compared numerical gradients with PyTorch gradients.
- Built a neural network using PyTorch.
- Implemented forward and backward propagation.
- Trained the model using Cross-Entropy Loss and Adam Optimizer.
- Evaluated training and validation accuracy.
- Used DataLoader for mini-batch training.
- Applied Dropout and Weight Decay.

## Tools and Libraries
- Python
- PyTorch
- NumPy
- Matplotlib

## Conclusion
This lab demonstrates how PyTorch uses Autograd and Backpropagation to train neural networks efficiently. It also highlights the importance of training loops, model evaluation, and regularization techniques.
