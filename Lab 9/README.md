# ARTI402 - Lab 09: Autoencoders

## Description
This lab explores Autoencoders in Deep Learning, focusing on image reconstruction, dimensionality reduction, latent representations, and noise removal.

## Tasks Completed
- Built an Autoencoder using PyTorch.
- Trained the model using MSE Loss and Adam Optimizer.
- Compared different bottleneck sizes.
- Visualized the 2D latent space.
- Evaluated extracted features using Logistic Regression.
- Implemented a Denoising Autoencoder.

## Tools and Libraries
- Python
- PyTorch
- NumPy
- Matplotlib
- Scikit-learn

## Conclusion
Autoencoders can learn meaningful features from unlabeled data by compressing and reconstructing images. Denoising Autoencoders can also reconstruct cleaner images from noisy inputs.
